# UrbanStyle Data Analytics Portfolio

**Fatima Rahimi** — Product Manager adding SQL, Python and Power BI to her toolkit.

10 weeks of real analysis for **UrbanStyle**, an Estonian fashion retailer moving from gut feeling to data-driven decisions.

## ⭐ Highlights
- **Customer segmentation:** 2,540 customers — 18% bring in 42.8% of revenue → [Week 7](week-7)
- **Automated pipeline:** 10,118 sales processed in 2.5 seconds via Supabase API → [Week 8](week-8)
- **Executive dashboard:** Tallinn store performance + data story → [Week 6](week-6)
